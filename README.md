# 🛕 SmartPilgrim

SmartPilgrim is a **Django-based temple management system** that streamlines the pilgrimage experience through online bookings, QR-based entry verification, AI assistance, donations, and emergency support.

🌐 **Live Demo:** http://13.51.199.189/

## 🚀 Features
- Temple Booking
- QR Code Verification
- AI Chatbot
- Online Donations
- SOS & Emergency Support
- Admin Dashboard

## 🛠 Tech Stack
**Django • Python • HTML • CSS • Bootstrap • SQLite • Gemini AI**

## ▶️ Run Locally
```bash
pip install -r req.txt
python manage.py migrate
python manage.py runserver
```
